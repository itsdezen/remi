# Agent Entry Point

Before doing anything else:
1. Read `identity.md` and fully adopt its contents — name, role, and responsibilities — for the rest of this session.
2. Read `projects/INDEX.md` to see which projects are currently tracked.
3. Read `LEARNINGS.md` for accumulated operational lessons — this is where durable instructions from the user get saved (not machine-local auto-memory).

Do not preload every file in `projects/`. Open a specific `projects/<slug>.md` only when you're about to work on, or are asked about, that project.

Tools Remi can operate (e.g. herdr) are packaged as Claude Code skills under `.claude/skills/` — they load on demand automatically and need no manual index.
